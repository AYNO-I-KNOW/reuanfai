ตารางที่ 4.2 การให้บริการในการดูแลสตรีหลังคลอด ตามองค์ประกอบ Six Building Blocks
   Six Building Blocks                                                             รายละเอียด
 1) การให้บริการ         1.1 วัตถุประสงค์และกลุ่มเป้าหมาย
 (Service delivery)          (1) วัตถุประสงค์
                                  1. ฟื้นฟูสภาพร่างกาย สมดุลธาตุ และระบบโลหิตของสตรีหลังคลอดบุตร
                                  2. ส่งเสริมการเข้าอู่ของมดลูก การขับน้ำคาวปลา และการฟื้นตัวของอวัยวะสืบพันธุ์
                                  3. บรรเทาอาการปวดเมื่อย อ่อนเพลีย ภาวะลมคั่ง เลือดคั่งหลังคลอดบุตร
                                  4. ส่งเสริมการสร้างและการหลั่งน้ำนมของสตรีหลังคลอดบุตรอย่างมีประสิทธิภาพ ควบคู่กับการดูแลและส่งเสริมสุขภาวะด้านจิตใจของ
                         สตรีในระยะหลังคลอด
                                  5. ป้องกันภาวะแทรกซ้อนระยะหลังคลอดบุตร
                             (2) กลุ่มเป้าหมาย
                                  1. สตรีหลังคลอดปกติหรือคลอดโดยใช้อุปกรณ์ช่วยคลอด โดยคลอดไปแล้ว 2-7 วัน แต่ไม่เกิน 3 เดือน
                                  2. สตรีหลังคลอดด้วยวิธีการผ่าตัดหน้าท้อง รวมกรณีผ่าตัดทำหมันหลังคลอดแล้ว 1 เดือน แต่ไม่เกิน 3 เดือน
                         หมายเหตุ : กรณีที่ต้องการให้บริการหลังคลอดให้กับสตรีหลังคลอดปกติ ภายใน 7 วันแรกหลังคลอด ต้องได้รับความเห็นชอบจากบุคลากรผู้มี
                         สิทธิ์ตรวจประเมินและสั่งการรักษาด้วย[50]
                         1.2 การให้บริการ[33, 49, 51]
                             1.2.1 การคัดกรอง : คัดกรองภาวะเสี่ยงด้านสุขภาพทั่วไปหลังคลอดบุตร, คัดกรองภาวะฉุกเฉินหลังคลอด เช่น ภาวะตกเลือด ติดเชื้อ ไข้สูง
                         ความดันโลหิตผิดปกติ, ประเมินความพร้อมในการรับบริการผดุงครรภ์ไทย เป็นต้น
