# ADR-0006: LINE — แชทใช้แจ้งเตือนอย่างเดียว

- สถานะ: Accepted · 2026-09-26 · ที่มา: Concept v2 §2.5; UX M0

## ตัดสินใจ
- คุณแม่เข้าระบบผ่าน LIFF ใน LINE OA ไม่ต้องลงแอป
- ข้อความในแชท **ห้ามมีชื่อโรค ชื่อยา หรือผลคัดกรอง** (คนในบ้านอาจหยิบมือถือไปอ่าน) ข้อความละ 1 ปุ่ม "เปิดดู" ที่พาเข้าหน้าเว็บ
- ใช้ template ตายตัว 8 แบบ (N1–N8) ตาม `docs/specs/notifications.md` เท่านั้น ไม่ generate ข้อความใหม่
- Rich menu มี 4 ปุ่ม: ปฏิทินของฉัน, เช็กอิน, นัดหมาย, ติดต่อด่วน (ปุ่มติดต่อด่วนต้องเด่นกว่าปุ่มอื่น)
- ข้อมูลสุขภาพทั้งหมดอยู่ในหน้าเว็บที่ต้อง auth เท่านั้น
- คุณแม่เลือกรูปแบบเตือนยาได้: ทุกรอบ หรือสรุปวันละครั้ง (ประหยัดค่าส่งข้อความด้วย)
