# ADR-0009: ขอบเขต AI — AI-1 การ์ดข้อเสนอ, AI-2 ธีมรีวิว

- สถานะ: Accepted · 2026-09-26 · ที่มา: Concept v2 §3.2–3.4; UX D7, P8, D6 · แก้เพิ่มบางส่วนโดย ADR-0014 (ป้าย P8, รายแพทย์)

## ตัดสินใจ
- **AI-1** (ผู้ช่วยวิเคราะห์บริการ): input = ชุดกฎ + ข้อความคู่มือพร้อมเลขหน้า + ตัวเลขรวมกลุ่ม + ธีมรีวิว output = การ์ดข้อเสนอ 6 ส่วน (สิ่งที่พบ, สิ่งที่คู่มือระบุ, สาเหตุที่เป็นไปได้ ≥2 ข้อ, ข้อเสนอ, ข้อมูลที่ต้องตรวจเพิ่ม, ความมั่นใจ) สถานะเริ่มต้นคือ "รอผู้เชี่ยวชาญพิจารณา" ข้อเสนอที่เกี่ยวกับเกณฑ์ → เป็นได้แค่ **ร่าง ruleset** (ADR-0002)
- **AI-2** (สรุปรีวิว): ลบข้อมูลระบุตัวตนก่อนส่ง → จัดกลุ่มเป็นธีม → สรุปรายเดือนระดับหน่วยบริการ ห้ามจัดอันดับแพทย์รายคน ถ้าข้อความบ่งบอกอาการไม่พึงประสงค์ → สร้าง `staff_alert` ให้เจ้าหน้าที่ตามต่อ
- ตัวเลขทุกตัว **คำนวณด้วยโค้ด** LLM เขียนได้แค่คำอธิบาย
- output ใช้ structured schema (AI SDK `generateObject`/`Output`) validate ก่อนบันทึก
- โมเดลเลือกจาก env `AI_MODEL` ผ่าน AI Gateway: ต้นแบบใช้ LLM เชิงพาณิชย์กับข้อมูลจำลอง ส่วนใช้จริงให้สลับเป็น Typhoon / Pathumma บนเซิร์ฟเวอร์ภาครัฐโดยไม่ต้องแก้โค้ด
- **ตัด speech-to-text** ที่เคยอยู่ใน v1 ออก เพราะไม่อยู่ใน v2/UX brief
- UI ที่เป็นผลจาก AI ต้องมีป้าย "ข้อเสนอจาก AI" / "สรุปโดย AI"
