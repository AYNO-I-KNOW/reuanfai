# ADR-0011: Auth — LIFF สำหรับแม่, Supabase Auth + role สำหรับเจ้าหน้าที่

- สถานะ: Accepted · 2026-09-26 · ที่มา: UX P1 · แก้เพิ่มโดย ADR-0013

## ตัดสินใจ
- **แม่**: web ได้ LIFF ID token → `POST /auth/line` → API verify กับ LINE (`/oauth2/v2.1/verify`, ตรวจ `aud` = channel id) → ออก session JWT ของ API (httpOnly cookie, 7 วัน — first-party ผ่าน /api rewrite, ADR-0013)
- **หน่วยบริการ / กรมฯ**: `POST /auth/staff` (username, password, unit, role) → API ใช้ Supabase Auth ตรวจรหัส → เช็กว่ามี `staff(user_id, unit_id, role)` ตรงกัน → ออก session
- Roles:
  - `doctor` — แพทย์แผนไทย: ตั้งตารางของตัวเอง, อ่านใบสรุป, บันทึกการรักษา, สั่งยา, ปลดล็อกส่งต่อ
  - `staff` — เจ้าหน้าที่: ยืนยันนัด, ตรวจสิทธิ์, ติดตามอาการไม่พึงประสงค์
  - `pharmacist` — ผู้ดูแลคลังยา: รับยาเข้า, ปรับยอด
  - `dtam_viewer` — กรมฯ: D1–D7
  - `rule_approver` — กรมฯ: D8 อนุมัติชุดกฎ
- เมนูฝั่งหน่วยบริการ/กรมฯ แสดงเฉพาะหน้าที่ role นั้นใช้ได้ **และ API ต้องบังคับซ้ำ**
- web ไม่มี Supabase key (ADR-0004)
