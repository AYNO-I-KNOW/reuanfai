# ADR-0019: chip แชทแม่ = คำถามจำเป็นที่ KB ตอบได้ กดแล้วส่งทันที

- สถานะ: Accepted · 2026-10-28 · ตัดสินโดยเจ้าของโปรเจกต์สั่ง · ที่มา: SPEC Q21 · แทน ADR-0016 **เฉพาะ** เนื้อหาและพฤติกรรมของ quick prompt ในแชท (`chat-topics.ts`) · ส่วนอื่นของ ADR-0016 ไม่เปลี่ยน · ต่อยอด ADR-0018

## บริบท
- quick prompt เดิม (ADR-0016) เป็นคำเปิดบทสนทนา กดแล้วเติมช่องพิมพ์ ต้องกดส่งอีกครั้ง และหลายข้อ KB ไม่มีเนื้อหา (ตอบข้อความตายตัว `kind: 'topic'`)
- แม่หลังคลอดพิมพ์ลำบาก · KB WHO เป็นภาษาอังกฤษ การค้นจากไทยเป็นอังกฤษได้ผลอ่อน

## ตัดสินใจ
1. chip ใต้แชท = เฉพาะคำถามจำเป็นต่อช่วงหลังคลอด (ราว 3–4 ข้อ/ช่วง: 0–7 วัน/ไม่ทราบ, 8–42 วัน, >42 วัน) ที่ KB ตอบได้จริง · ผ่าคลอดเพิ่มข้อเฉพาะผ่าคลอด และตัดข้อแผลฝีเย็บ
2. กด chip = ส่งทันที ไม่ผ่านช่องพิมพ์ · ปิดการกดระหว่างรอคำตอบ
3. chip แยก `label` (ไทยสั้น แสดงบนปุ่มและเป็น bubble ของแม่) กับ `query` (ส่งไป `/kb/ask`) · `query` ต้องตรงกับรายการใน `knowledge/suggestions.json` ทุกตัว (verify แล้วว่าตอบได้) · ข้อ WHO ใช้ `query` ภาษาอังกฤษ แม่ไม่เห็น
4. bubble `ChatInvitation` แสดง `label` และเปิดแชทด้วย `?question=label&query=...` → แชทส่งอัตโนมัติครั้งเดียวตอนเปิด (ไม่เติมช่องพิมพ์)
5. `TOPIC_REPLIES` ใน `kb-lib.ts` คงไว้ให้คำเปิดเดิมที่อาจมาทาง `?question=` เก่ายังได้ข้อความตายตัว · ไม่มีโค้ด web ส่งแล้ว

## ไม่เปลี่ยน
- ส่วนอื่นของ ADR-0016 (ติดต่อด่วน, โปรไฟล์, journal, bottom nav) · ADR-0001, 0005, 0006, 0009, 0018

## ผลที่ตามมา
- รายการ chip ต้องตามไฟล์ `suggestions.json` · ถ้าตัดรายการออกจากไฟล์ ต้องแก้ `chat-topics.ts` ตาม
- ยังไม่ผ่าน `DESIGN-REVIEW.md` (Q25)
