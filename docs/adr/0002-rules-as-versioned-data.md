# ADR-0002: ชุดกฎเก็บเป็น data มีเวอร์ชันและเลขหน้า

- สถานะ: Accepted · 2026-09-26 · ที่มา: Concept v2 §2.1 ข้อ 4, §3.4 · แก้เพิ่มบางส่วนโดย ADR-0014 (การแสดงเหตุผลบนจอแม่)

## ตัดสินใจ
- ชุดกฎ (`ruleset`) เก็บเป็น JSON ตาม schema ใน `docs/specs/rules.md` แก้กฎได้โดยไม่ต้องแก้โค้ด engine
- กฎทุกข้อต้องมี `id`, `source` (ชื่อเอกสาร), `page` และข้อความอ้างอิง
- เวอร์ชันแบบ semver-ish (`1.0`, `1.1`) สถานะเป็น `draft | active | rejected` และ active ได้ทีละ 1 เวอร์ชัน
- screening / check-in / prescription warning ทุกรายการเก็บ `ruleset_version` ที่ใช้ตอนนั้น (ตรวจย้อนหลังได้)
- เปลี่ยนจาก draft เป็น active ได้เฉพาะ role `rule_approver` (D8) และต้องบันทึกว่าใครอนุมัติ เมื่อไร

## ผลที่ตามมา
- ruleset v1.0 = ร่างของทีม แต่ **ยังไม่ผ่านการตรวจจากแพทย์แผนไทย** (Concept v2 §5.4) UI ต้องไม่อ้างว่าเป็นเกณฑ์ทางการ
