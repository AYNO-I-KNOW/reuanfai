# ADR-0008: กรมฯ เห็นเฉพาะข้อมูลรวมกลุ่ม, n<5 ซ่อน

- สถานะ: Accepted · 2026-09-26 · ที่มา: Concept v2 §2.4; UX D1, D7

## ตัดสินใจ
- role กรมฯ อ่านได้เฉพาะ SQL views `agg_*` ซึ่งกรองแล้วว่ามี consent `aggregate` ที่ยังไม่ถอน
- ช่องไหนมีน้อยกว่า 5 คน → API คืน `{ suppressed: true }` แล้ว UI แสดง "น้อยกว่า 5"
- AI-1 สร้างการ์ดได้เมื่อกลุ่มที่ใช้เทียบมี ≥ 30 เคส ถ้าน้อยกว่านั้นติดป้าย "ข้อมูลยังน้อย"
- ทุกหน้าของกรมฯ มีป้าย "ข้อมูลรวมกลุ่ม ไม่ระบุตัวบุคคล"
- ตัวกรองของทุกหน้าใช้ชุดเดียวกัน: เขตสุขภาพ, จังหวัด, หน่วยบริการ, ช่วงเวลา, วิธีคลอด

## ข้อจำกัดที่รู้อยู่
ซ่อน n<5 อย่างเดียวยังโดน differencing attack ได้ (เอาผลรวมลบช่องอื่น) รอบต้นแบบยอมรับความเสี่ยงนี้เพราะเป็นข้อมูลจำลอง แต่ก่อนใช้จริงต้องทำ complementary suppression
