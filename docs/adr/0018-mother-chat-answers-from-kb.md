# ADR-0018: แชทแม่ตอบจาก KB ผ่าน /kb/ask

- สถานะ: Accepted · 2026-10-28 · ตัดสินโดยเจ้าของโปรเจกต์สำหรับต้นแบบ · ที่มา: SPEC Q21, Q25, Q28 · ต่อยอด ADR-0017 (ไม่แก้ ADR ที่ Accepted แล้ว)

## บริบท
- แชทผู้ช่วยฝั่งแม่ (`ruenfai/chat`) ตอบข้อความตายตัว (Q21) · KB `POST /kb/ask` (ADR-0017) ตอบจากเอกสารอ้างอิงพร้อมที่มาได้แล้ว
- ADR-0017/Q28 ระบุว่า agent ถาม-ตอบฝั่งแม่ต้องมี ADR แยก

## ตัดสินใจ
1. หน้าแชทแม่เรียก `POST /api/kb/ask` (rewrite ไป api ตาม ADR-0013) แทนข้อความตายตัว · quick prompt/`ChatInvitation` ส่งข้อความผ่านทางเดียวกัน
2. ตอบ **เฉพาะ** จาก KB พร้อมที่มา (`apa` + หน้า, ลิงก์ถ้ามี `url`) · ทุกคำตอบมีป้าย "สรุปโดย AI"
3. system prompt ห้ามวินิจฉัย/คัดกรองผู้ใช้ ห้ามแนะนำยาหรือขนาดยารายบุคคล (ADR-0001, §7)
4. ไม่พบใน KB → `NOT_FOUND` + `suggestions` (คำถามที่ KB ตอบได้ใกล้สุด) แสดงเป็นชิป "หรือคุณหมายถึง" กดแล้วถามต่อ
5. ใช้ Gemini free tier กับคำถามจำลองเท่านั้น (Q28, ADR-0012) · ห้ามมีข้อมูลจริง/ข้อมูลสุขภาพของแม่จนกว่าจะมี ZDR · ไม่บันทึกข้อความแชท · ไม่มีข้อมูลสุขภาพใน LINE (ADR-0006)
6. error แสดงข้อความสุภาพ ไม่แสดง error ดิบ · 429 แจ้งให้ลองใหม่ภายหลัง
7. LLM fallback: env `AI_FALLBACK_MODEL` (ไม่บังคับ, base URL/key เดียวกัน) — ถ้าโมเดลหลักตอบ HTTP 429 ลองใหม่ 1 ครั้งด้วยโมเดลสำรอง (นับในงบ LLM ต่อวัน) · `model` ใน response = โมเดลที่ตอบจริง · cache key ไม่เปลี่ยน

## ไม่เปลี่ยน
- ADR-0001, 0004 (web ไม่ต่อ DB ตรง), 0006, 0009 (AI-1/AI-2), 0012, 0017
