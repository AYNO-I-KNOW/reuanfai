# ADR-0000: Concept และ UX brief ล็อก

- สถานะ: Accepted · 2026-09-26

## บริบท
ระบบนี้ออกแบบตามเอกสารข้อเสนอที่ส่งกรมการแพทย์แผนไทยฯ ถ้าโค้ดหรือ design ค่อย ๆ เบี่ยงจากเอกสาร ระบบจะไม่ตรงกับที่เสนอไว้

## ตัดสินใจ
- source of truth: `docs/concept/ConceptPaper_v2.pdf` + `docs/concept/UX-Brief_v1.pdf`
- `docs/concept/archive/ConceptPaper_v1.pdf` ใช้อ้างอิงอย่างเดียว v2 มาแทน v1 (ตัด STT เสียง, เพิ่มจองคิว/ยา/คลัง/รีวิว)
- ห้ามแก้ concept, UX brief หรือ ADR ที่ Accepted แล้ว **เว้นแต่เจ้าของโปรเจกต์ (เกรพ) สั่ง** ถ้าต้องเปลี่ยน ให้เขียน ADR ใหม่มา supersede
- spec ใน `docs/specs/` ต้องย้อนไปหาเอกสารต้นฉบับได้ ถ้าขัดกัน ให้ถือเอกสารต้นฉบับ

## ผลที่ตามมา
