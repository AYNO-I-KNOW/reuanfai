# ADR-0012: ต้นแบบใช้ข้อมูลจำลอง ไม่เชื่อมระบบจริง

- สถานะ: Accepted · 2026-09-26 · ที่มา: Concept v2 §3.4, §5.2 · แก้เพิ่มบางส่วนโดย ADR-0014 (ป้ายฝั่งหน่วยบริการ)

## ตัดสินใจ
- ข้อมูลทั้งหมดมาจาก `supabase/seed.sql`: หน่วยบริการสมมติ, แม่สมมติ, คลังยา, รีวิว, ตัวเลข dashboard
- ทุกหน้าฝั่งหน่วยบริการ/กรมฯ มีป้าย "ข้อมูลจำลอง" และตัวเลขใน dashboard มี "(จำลอง)"
- ไม่เชื่อม สปสช. / e-Claim / 43 แฟ้ม / ระบบโรงพยาบาล ส่วนการนับสิทธิ์นับเฉพาะครั้งที่จองผ่านเรือนไฟ (UI ต้องบอกข้อนี้)
- เจ้าหน้าที่ต้องติ๊ก "ตรวจสอบสิทธิผู้รับบริการแล้ว" ก่อนบันทึก เพราะระบบไม่ได้ตรวจสิทธิ์ให้จริง
- รหัสกิจกรรม/ICD-10-TM ใช้ตามคู่มือ แต่ต้องเช็กกับ สปสช. ทุกปี
