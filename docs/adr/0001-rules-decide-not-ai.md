# ADR-0001: กฎจากคู่มือเป็นผู้ตัดสิน ไม่ใช่ AI

- สถานะ: Accepted · 2026-09-26 · ที่มา: Concept v2 §3.1, §3.3

## ตัดสินใจ
การคัดกรอง, กรอบเวลา, นัดหมาย, สิทธิ์ และคำเตือนข้อห้ามยา คำนวณด้วย **rules engine แบบ deterministic** จากชุดกฎที่เขียนตามคู่มือ ใส่ input เดิมต้องได้ผลเดิมทุกครั้ง และทุกผลต้องบอกได้ว่ามาจากกฎข้อไหน

AI ห้ามทำสิ่งต่อไปนี้ (ห้ามทั้ง AI-1 และ AI-2):
1. วินิจฉัยโรค
2. ตัดสินว่าคุณแม่เข้าเกณฑ์ข้อไหน / ให้คะแนนความปลอดภัย / บอกว่าใครพร้อมรับหัตถการ
3. อ่านหรือแปลข้อความ "ไม่แน่ใจ" ที่คุณแม่เขียน
4. เปลี่ยนกฎหรือเส้นทางส่งต่อเอง
5. เห็นข้อมูลรายคน (AI-1 เห็นแค่ข้อมูลรวมกลุ่ม ส่วน AI-2 เห็นรีวิวที่ลบข้อมูลระบุตัวตนแล้ว)

## ผลที่ตามมา
- ใน engine ห้ามมี LLM call; code review ต้องเช็กข้อนี้
- คนเป็นผู้ตัดสินขั้นสุดท้ายเสมอ ระบบทำหน้าที่ชี้ตามคู่มือ ("ต้องดำเนินการภายใต้ดุลยพินิจของแพทย์ผู้ทำการรักษา" คู่มือ หน้า 93)
