# ADR-0007: Consent 2 ชั้น, การแชร์รายหน่วย, log การเปิดใบสรุป

- สถานะ: Accepted · 2026-09-26 · ที่มา: Concept v2 §3.4 (พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล 2562 ม.26); UX M1, M6-4, M11

## ตัดสินใจ
- Consent 2 ชั้น แยกกัน:
  - `care` (จำเป็น) — ใช้คัดกรองและนัดหมาย
  - `aggregate` (ไม่บังคับ, **ค่าเริ่มต้น = ไม่ติ๊ก**) — ใช้แบบรวมกลุ่มกับคนอื่นเพื่อพัฒนาบริการ
- การแชร์ใบสรุปให้หน่วยบริการเป็นราย **หน่วย + ระยะเวลา** (`shares.until`) คุณแม่ต้องติ๊กเองทุกครั้งที่จอง (ห้าม pre-check)
- หน่วยบริการเปิดใบสรุปได้เฉพาะตอนมี share ที่ยังไม่หมดอายุ ทุกครั้งที่เปิดบันทึก `access_log(staff, mother, at)`
- ถอน consent หรือยกเลิกแชร์ได้ทุกเมื่อ (M11) → มีผลกับข้อมูลใหม่ทันที ส่วนข้อมูลที่รวมกลุ่มไปแล้วแก้ย้อนหลังไม่ได้ (ต้องแจ้งคุณแม่)
- ขอลบข้อมูล → ลบข้อมูลส่วนบุคคลออก ส่วนบันทึกการรักษาที่หน่วยบริการบันทึกไว้เก็บตามนโยบายของหน่วย
- **ไม่เอาข้อมูลไปฝึก AI** (ใช้ provider ที่ไม่เก็บข้อมูล / zero data retention)
