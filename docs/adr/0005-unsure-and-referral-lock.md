# ADR-0005: "ไม่แน่ใจ" = ให้ประเมินก่อน, เข้าเกณฑ์ส่งต่อ = ล็อกการจอง

- สถานะ: Accepted · 2026-09-26 · ที่มา: Concept v2 §2.1 ข้อ 1–3, §2.3 ข้อ 2–3; UX M3, M4-R, M8 · แก้เพิ่มบางส่วนโดย ADR-0014 (ปุ่มโทรปรึกษา, ข้อความกำกับผล)

## ตัดสินใจ
1. คำตอบมี 3 ค่า: `yes | no | unsure` ทุกคำถามต้องมีปุ่มขนาดเท่ากัน สีเดียวกัน
2. `unsure` **ห้ามถือเป็น "ผ่าน" เด็ดขาด** → หัตถการที่เกี่ยวเป็น `evaluate` (ให้ประเมินก่อน) คุณแม่จองได้แค่ "นัดประเมิน" + มีช่องเล่าเพิ่ม + ปุ่มโทรปรึกษา
3. ถ้าตอบ `yes` ในข้อที่เป็นเกณฑ์ส่งต่อ → ไปหน้า M4-R ทันที และสร้าง `referral_lock` ปิดการจองหัตถการทั้งหมด **จนกว่าแพทย์แผนไทยจะปลดล็อก**
4. ข้อความ "ไม่แน่ใจ" ส่งให้ผู้ประกอบวิชาชีพอ่านในใบสรุป (P4) โดยไม่ผ่าน AI (ADR-0001)
5. ผลลัพธ์พูดว่า "ไม่พบข้อห้ามจากข้อมูลที่แจ้ง" หรือ "ผลจากข้อมูลที่คุณแจ้ง · ไม่ใช่ผลการวินิจฉัย" **ห้ามใช้คำว่า "ปลอดภัย"**

## เหตุผล
ถ้าตอบไม่แน่ใจแล้วผ่าน คุณแม่จะมีเหตุผลให้ตอบเบากว่าความจริงเพื่อจองให้ได้ ซึ่งเป็นเงื่อนไขหยุดโครงการ (Concept v2 §5.4)
