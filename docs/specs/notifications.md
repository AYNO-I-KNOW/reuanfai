## กฎ
- เวลาทั้งหมดใช้ Asia/Bangkok
- ยกเลิกนัด → ลบ outbox ของนัดนั้นที่ยังไม่ได้ส่ง (N3, N6)
- `paused` dose (กดมีอาการผิดปกติ) → ไม่ส่ง N5
- mother ถูกลบ / unfollow → ไม่ส่ง mark `error = 'unfollowed'`
- ส่งพลาด → retry ตอน dispatch รอบถัดไป, `attempts ≤ 3`
- ส่งด้วย LINE Messaging API push (`/v2/bot/message/push`) เป็น template message 1 ปุ่ม
