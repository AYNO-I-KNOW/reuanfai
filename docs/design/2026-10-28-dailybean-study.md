# ศึกษา DailyBean จากภาพอ้างอิง — 28 ตุลาคม 2569

สถานะ: research/ข้อเสนอ ยังไม่มีการเปลี่ยน UI เรือนไฟจากงานศึกษานี้

## การระบุแอป

DailyBean ของ BlueSignum: ยืนยันจากหน้า official, Apple App Store editorial และรูปแบบ mood5ระดับ/Blocks/ปฏิทิน mood ในภาพผู้ใช้ ภาพเป็นธีมดาวเคราะห์ ไม่ยืนยันชื่อธีมเฉพาะหรือเลขเวอร์ชันจาก screenshot อย่างเดียว สัญลักษณ์ Duolingo ใน Dynamic Island เป็น UI ภายนอกแอป ไม่ใช่ชื่อแอปบันทึก

## สิ่งที่สังเกตจากภาพ

- Mood หลัก5ระดับแยกจาก Emotions รายละเอียด เช่น sad/anxious/relaxed; People, Meals, Health, Hobbies, Chores, Work, Beauty, Weather แยกหมวด
- บล็อกเป็นการ์ดผิวเดียวใน dark mode มีหัวข้อและ chevron; icon grid4คอลัมน์สม่ำเสมอ พร้อม label ใต้ทุกไอคอน
- Mood ที่เลือกมีสี ตัวเลือกอื่นเทา; ภาพนิ่งยังไม่ยืนยันสี selected ของกิจกรรมอื่นหรือกฎ single/multiple choice แต่ละบล็อก
- Today’s note/photo อยู่หลังหมวดแตะเลือก; Sleep/Exercise มี Import และปุ่มเพิ่ม ไม่แสดงฟอร์มยาวทันที
- Date/back/settings ยึดส่วนหัว; Done ยึดแถบล่าง ต่างจากเนื้อหาเลื่อน เป็น action บันทึกเดียว
- ปฏิทินสรุป mood ด้วยตัวละครต่อวัน; วันที่ยังไม่มีรูปแสดงวงกลมสีเทา วงขอบเขียวแสดงวันที่28ในภาพ ไม่อนุมานว่าเป็น selected/today จากภาพอย่างเดียว
- ไม่สามารถประเมิน animation, haptic, scroll physics หรือ save correctness จากภาพนิ่ง

## หลักการที่ตีความจากการจัด UI

การบันทึกเริ่มจากเลือก ไม่บังคับเริ่มด้วยเขียนยาว: เลือกอารมณ์ภาพรวม → เติมบริบทด้วยไอคอน → เรื่องราว/รูป → บันทึก → เห็นร่องรอยในปฏิทิน การ์ดเป็นกลุ่มคำถามที่มีหน้าที่และยุบได้ ต่างจากเพิ่มกล่องตกแต่งอย่างเดียว

ข้อดีคือเริ่มง่ายและมอง pattern รายเดือนได้เร็ว จุดที่ควรระวังคือรายการยาวและหมวดจำนวนมาก ธีมตกแต่งอาจแย่งเนื้อหา และ icon อย่างเดียวไม่บอกเหตุการณ์ทั้งหมด จึงยังต้องมี label/ข้อความประกอบ

## สิ่งที่เว็บไซต์ทางการยืนยัน

- Basic/Custom/Special Blocks และการซ่อนหมวดที่ไม่ใช้; Special Blocks รองรับ syncข้อมูล เช่น sleep/exercise และจัดการการเชื่อมต่อจาก settings
- Themes เปลี่ยนพื้นหลังกับ mood character; มีแบบเปลี่ยนชุด, เฉพาะ bean, และ live theme
- Report รวม mood flow, สัดส่วน mood, กิจกรรมที่บันทึกบ่อย และข้อมูลเชิงลึกบางส่วน การเห็นกิจกรรมร่วมกับ mood ไม่ใช่หลักฐานเชิงเหตุผลหรือการวินิจฉัย

## ข้อเสนอสำหรับเรือนไฟ ยังไม่อนุมัติให้ implement

1. คง mood หลัก5ระดับ แล้วให้เลือกรายละเอียดความรู้สึกเพิ่มเติมแบบ optional
2. คัดหมวดที่ตรงการดูแลหลังคลอด เช่น พักผ่อน/การช่วยเหลือ/กิจกรรมประจำวัน ไม่ยกทุกหมวด lifestyle มาใส่
3. ใช้ภาพและ label ในกริดที่สม่ำเสมอ พร้อมการจัดกลุ่มที่ยุบได้ คงปุ่มบันทึกมองเห็นง่าย
4. เพิ่มมุมมองปฏิทินอารมณ์เพื่ออ่านภาพรวมเดือน โดยคงทางเข้ารายละเอียดบันทึกและไม่ตีความ mood เป็นผลคัดกรองทางคลินิก
5. ไม่ยืม asset หรือลายดาวเคราะห์โดยตรง ใช้ภาษาภาพและสีเรือนไฟ
