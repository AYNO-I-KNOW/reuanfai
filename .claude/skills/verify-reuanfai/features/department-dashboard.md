# แดชบอร์ดกรมฯ

เจ้าหน้าที่กรมฯ ใช้ `/department` ดูภาพรวมเครือข่ายแบบรวมไม่ระบุตัวบุคคล 5 แท็บ พร้อมตัวกรองและการปิดบังค่าน้อยกว่า 5 (ADR-0008)

## Sub-features

- `dept-overview` แท็บ "ภาพรวมเครือข่าย" (ลงทะเบียน, ผ่านการคัดกรอง, จองนัดหมาย, มารับบริการ)
- `dept-outcomes` แท็บ "ผลลัพธ์และคุณภาพ"
- `dept-safety` แท็บ "ความปลอดภัย" (เข้าเกณฑ์ส่งต่อ, เหตุการณ์ไม่พึงประสงค์)
- `dept-medicine` แท็บ "ยาและคลังเครือข่าย"
- `dept-ai` แท็บ "ข้อเสนอจาก AI"
- `dept-filters` ตัวกรอง "ช่วงเวลา", "เขตสุขภาพ", "จังหวัด" และหน่วย
- `dept-suppression` ค่าที่ n<5 แสดงเป็น "น้อยกว่า 5"

## How to get to it (user POV)

- เปิด `/department` แล้วใช้ nav ใน sidebar (ปุ่มตามชื่อแท็บ)
- ลิงก์ "ระบบหน่วยบริการ" ใน sidebar ของ `/department` ไป `/clinic`
- "ออกจากระบบ" พาไป `/login`

## Driving it with drive.mjs

Preconditions:

- `scripts/doctor.sh` ผ่าน, context ใหม่, journey ตั้ง `export const viewport = {width: 1440, height: 900}`
- ยังไม่มี journey สำหรับ feature นี้ recipe มาจากการอ่าน source ยังไม่ได้รันจริง

- **เปิด.** `page.goto(url('/department'))` เห็น h1 "ภาพรวมเครือข่าย" และข้อความ "จำลอง · ข้อมูลรวมไม่ระบุตัวบุคคล"
- **เปลี่ยนแท็บ.** `page.getByRole('button', {name: 'ความปลอดภัย'}).click()` h1 เป็น "ความปลอดภัย" ปุ่มมี `aria-current="page"`
- **ดูการปิดบังค่า.** ในแท็บ "ความปลอดภัย" ตรวจว่าค่าตัวเลขเล็กแสดงเป็น "น้อยกว่า 5" (`getByText('น้อยกว่า 5')`) ไม่มีเลข 1-4 โผล่ในการ์ดสรุป
- **ตัวกรอง.** เลือก "เขตสุขภาพ" แล้ว "จังหวัด" ตัวเลือกจังหวัดแคบลงตามเขต (ตัวกรองเป็นคอมโพเนนต์ `Select` ที่มี label ตามข้อความ ยืนยัน role จริงตอนเขียน journey)
- **ข้อเสนอ AI.** `page.getByRole('button', {name: 'ข้อเสนอจาก AI'}).click()` เห็น h2 "ข้อเสนอเพื่อพิจารณา"
- **Proof.** ARIA snapshot + screenshot ต่อแท็บ; ใช้ ARIA snapshot ยืนยันว่าไม่มีข้อมูลระดับบุคคล (ชื่อ/เบอร์) ในหน้า

## Gotchas

- แท็บไม่มี URL (`useState`) `page.goto` กลับแท็บแรกเสมอ
- ตัวกรองและ sidebar อาจย่อ: `aria-label` ของปุ่ม sidebar ใช้ได้ทั้งสองสถานะ แต่ปุ่มย่อ/ขยายเปลี่ยนชื่อ (`ย่อ Sidebar` / `ขยาย Sidebar`)
- หน้านี้อ่าน `reuanfai-care-demo-v1` (ผ่าน `useCareDemo`) ตัวเลขอาจเปลี่ยนเมื่อ context เดียวกันมีการจอง/จ่ายยา; ยังไม่ได้ยืนยันว่าตัวเลข "จองนัดหมาย" ขยับตามคิวใหม่
- ข้อมูลทั้งหมดเป็น mock; ห้ามเรียกว่าข้อมูลจริง กรมฯ ต้องเห็นเฉพาะ `agg_*` + suppression n<5 (ADR-0008) จอใดเปิดข้อมูลรายบุคคล ให้รายงานเป็นข้อบกพร่อง
- ไม่มีการเรียก network; `externalRequests` ต้องว่าง
